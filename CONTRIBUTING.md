# Contributing

Thanks for taking a look.

- **A problem with a tool** (wrong data, a failed run, a missing field): open an issue on the tool's Store page, where it is tracked and answered.
  - Company Job Board Feeds: https://apify.com/reliable-apps/company-job-board-feeds/issues
  - Google Trends API & Scraper: https://apify.com/reliable-apps/google-trends-reliable/issues
- **A problem with an example in this repository** (it does not run, or does not match the tool's output): open an issue here with the command you ran and the error, with your token removed.
- **A new example**: pull requests are welcome. Keep it short, use the `APIFY_TOKEN` environment variable, set a maximum cost per run, and use public data only. No logins, no personal data, no captcha or block bypass.

Never paste an API token into an issue, a pull request or a commit.
